// 01 — about

Researcher mindset.
Consultant discipline.

I'm Sachin Mishra, a security researcher and bug bounty hunter from Raipur, India. I test live, real-world applications where a missed bug has a real cost — across fintech, healthcare, e-commerce, SaaS and AI products — and I'm ranked in the top 1% of researchers on Com Olho.

I started in 2026 and went from first report to a top-1% Com Olho ranking and ten Hall of Fame recognitions within months, by testing methodically rather than running scanners. I also build with Gemini, ADK and MCP, which lets me test AI systems from the builder's side as well as the attacker's.

My approach is recon → confirm → prove one value → stop. No inflated severities, no scanner noise dressed up as findings. If it isn't exploitable and reproducible, it doesn't go in the report.

I follow the OWASP testing methodology section by section, then go beyond the checklist into business logic, authorization and chained attack paths — where the serious bugs usually live.

What I test

Scoped, manual and evidence-driven. Every engagement ends with a report your developers can act on the same day.

Web Application Pentest

Deep manual testing mapped to OWASP — authentication, sessions, access control and business logic.

  • OWASP Top 10 + ASVS coverage
  • AuthZ / IDOR / privilege escalation
  • Business-logic abuse

API Security Testing

REST, GraphQL and gRPC assessments focused on object-level authorization and data exposure.

  • BOLA / BFLA / mass assignment
  • JWT & OAuth flaws
  • Rate limiting & injection

Mobile App Security

Android and iOS static + dynamic analysis, traffic interception and runtime instrumentation.

  • Insecure storage & hardcoded secrets
  • Pinning & root-detection bypass
  • Exported components

AI / LLM Security

Red-teaming for chatbots, agents and MCP tooling — where the attack surface is new and under-tested.

  • Prompt injection (direct & indirect)
  • Tool / agent abuse & data exfil
  • System-prompt & secret leakage

Cloud & Attack Surface

External attack-surface mapping and cloud misconfiguration review across AWS, GCP and Azure.

  • Asset & subdomain discovery
  • Storage / IAM exposure
  • Takeover & leak checks

Secure Code Review

Source-level audit to trace untrusted input to dangerous sinks and catch what black-box testing misses.

  • Injection & deserialization sinks
  • Auth & crypto misuse
  • Dependency risk
// 03 — process

From scope to sign-off

A transparent, four-stage engagement with no surprises.

01

Scope & Recon

Rules of engagement, asset list and auth model agreed up front. Then passive and active mapping of the real attack surface.

02

Exploit & Validate

Manual testing and chained attacks. Every finding is confirmed with a minimal, safe proof of concept.

03

Report & Debrief

Executive summary, technical write-up with replay steps, CVSS-rated risks and prioritised remediation.

04

Retest

After your fixes ship, I re-verify each finding and confirm closure.

// 07 — principles

How I work

Honest severity

A finding is rated for the impact I can actually demonstrate — not the one that sounds scariest. You get a report you can trust and prioritise from.

Zero scanner noise

Tools speed up recon; they don't write the report. Every issue is manually confirmed and reproducible before it reaches you.

Minimal, safe proof

I prove impact with the least invasive PoC possible. No data destruction, no service disruption, no going beyond scope.

Engineer-first reporting

Clear title, impact, exact steps, and a concrete fix. Written so a developer can reproduce and patch without a meeting.
